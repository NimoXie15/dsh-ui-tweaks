# dsh-ui-tweaks

给 DSH（DeepSeek Harness）的 Web UI 的一批界面微调：装上即生效，无需配置。

官方界面有几处用得难受：宽表格会撑出对话区、滚动条贴在最右端要横跨半屏、Windows 关闭「动画效果」时前端动画一起没了、会话释放后回合尾的改动卡会消失、插件更新只能去插件管理页挨个看。本插件一次性修掉这些，另附桌面客户端的窗口记忆。

## 功能

**宽表格越界修复**
- ≥4 列的宽表格不再撑出对话区，收敛回正文列并支持横向滚动。

**对话区左侧滚动条**
- 在右侧宽度调整条的左边放一条自绘滚动条：拖拽、点轨道翻页、滚轮手感与原生一致，主题跟随明暗，只在会话页出现。

**回合尾改动卡**
- 官方「本回合改动」卡在会话释放后（切走会话、重启客户端、重开旧会话）原本会消失；本插件用会话日志里的文件改动数据补上，卡片仍由**官方组件原样渲染**——卡头、统计、4 行折叠、hover 预览、右侧「改动审查」都与活会话一致。
- 官方本来就不会画的两种情形（关着「显示编码工具视图」、该回合没有官方改动记录）才由插件画一张同款，不会与官方卡重复。
- 会话释放后仍能打开官方 Review；里面的「打开 / 显示位置 / 打开方式」由插件交给 Host 执行（会话活着时走官方原路）。应用列表照官方只列系统关联里的真实应用：主按钮＝列表第一个应用，菜单底部固定「显示文件位置」；枚举不到时只剩「显示文件位置」。
- 口径：只含**文件工具**（写/改文件）造成的改动；数字按回合首末的**净变化**计。
- 0.2.5 修正：活会话的「改动审查」走官方**整文件对比**；会话释放后由插件补位，补位时**逐段**还原（每处改动各成一段，不再把文件不同位置的两处改动拼成一段），并按当前文件内容把每段的行号对到真实位置。哪一段对不上，标题会标「（片段内行号）」，表示这段的行号只能按片段内序号显示。

**改动审查默认单栏**
- 侧边栏「改动审查」打开对比时默认单栏（unified），不再一上来就是左右双栏；顶部按钮随时可切回双栏。
- 想恢复官方默认（双栏）：控制台执行 `localStorage.setItem("dshuiw.reviewUnified","0")` 后刷新。

**动画修复**
- Windows 关闭「动画效果」时，清除因此失效的界面动画；web 与桌面客户端都生效。

**插件更新检查**
- 插件管理页「已安装」标题行右侧多一组按钮：检查更新、逐个更新、全部更新与取消（不检查 dsh 本体与官方 `@deepseek-ai` 插件）。
- 未过 pnpm 发布冷静期的版本标「冷静期中」并给出可更新时间，到点自动恢复；确需立刻安装可走「强制更新」。声明了更高 DSH 版本的标「DSH 不符」。两者默认都不给装。
- 「强制更新」写入的豁免会在该版本满 24 小时后自动清理；不能装完立刻删——pnpm 每次安装都校验整个 lockfile，提前删会让后续安装整体被拒。
- 更新首选原地覆盖；DSH 开着热重载时会拒绝原地覆盖版本，这时才退回「先卸载 → 再安装」。卸载前会先验证更新来源可达（目标版本在 registry 上存在、安装包能下载），验证不通过就**不卸载**，避免卸载成功却装不回来。
- 更新成功后顶部提示「重启客户端后生效」；「立即重启」会先告诉你有没有会话在跑，**任何情况都要你确认**才执行。
- 面板与弹窗支持纯键盘操作（Tab / 回车 / 空格 / Esc），焦点环与官方控件一致。
- 列表滚动条是**浮层拇指**（与对话区那条同款）：不占行内宽度（Windows 原生条会吃掉 17px），颜色跟随主题，可拖动，点轨道会跳过去。

**窗口记忆（仅桌面客户端）**
- 记住上次的窗口大小、位置与最大化状态，下次启动自动还原；不修改官方任何文件，卸载即恢复。
- 状态存在 profile 的 `ui-tweaks/window-state.json`，删掉即重置。

## 安装

> 命令里的 `<安装目录>`、`<PluginName>` 等尖括号内容是占位符，替换成你的实际值。

浏览器版（`web`）：

```sh
dsh plugin --profile web add @nimoxie/dsh-ui-tweaks
```

装完重启服务（关掉再 `dsh web`）。

桌面客户端：桌面 profile **保留给客户端**，PATH 上那个 `dsh`（npm 全局装的）会被拒。但客户端**自带的那份 CLI 可以** —— 它就在安装目录里，和「插件管理」页走的是同一套实现：

```sh
# Windows 桌面端；<安装目录> 指 DeepSeek Harness.exe 所在文件夹
"<安装目录>\resources\runtime\cli\bin\dsh.cmd" plugin --profile desktop add @nimoxie/dsh-ui-tweaks
```

不想敲命令，也可以在客户端「插件管理」页添加包名 `@nimoxie/dsh-ui-tweaks`，重启客户端生效。

卸载（CLI 可管理的 `web` 环境）：

```sh
dsh plugin --profile web remove @nimoxie/dsh-ui-tweaks
```

别人也可以从 GitHub 或本地目录装（开发用）：

```sh
dsh plugin --profile web add github:NimoXie15/dsh-ui-tweaks
dsh plugin --profile web add link:/absolute/path/to/dsh-ui-tweaks
```

> **要求**：dsh `>= 0.2.0-rc.1`（需要 `remote.pluginManager` / `remote.pluginInventory` 接口）。
>
> 升级插件后界面没变化，按 **Ctrl+Shift+R** 强刷一次（浏览器可能还在用缓存的旧版本）。
>
> 刷新只换前端代码；插件的 host 半区（更新检查、改动卡打开文件等本机路由）要**完全退出客户端再打开**才会换。

## 已知限制

- 非 npm 来源的插件没有可比的 registry 版本，直接跳过比对：`link:` / `file:` 标「本地链接」，`git:` / `github:` / `http` 直装标「Git 直装」（例：`github:Fisfzy/dsh-ego-browser` 装的是仓库源码，与 npm 上的同名包不是一回事）。
- 更新**已经装过**的插件时优先原地覆盖；只有当客户端开着热重载、安装接口不允许原地覆盖时，才退回「先卸载 → 再装回」。退回前会先验证更新来源可用（目标版本在 pnpm 配置的 registry 上存在、安装包能下载），**验证不通过就不卸载**。装失败会自动回滚到原版本，原因（pnpm 输出与日志位置）写在该行，点它可重试。
- 一次要重链几十个包时 pnpm 可能**安静地跑好几分钟**：行内显示「pnpm 仍在运行 …」，不会提前判超时；超过 15 分钟才判超时，若这次中途卸载过，会自动复查清单并尽量装回旧版本。
- 本插件**不能从面板自更新**：更新会先卸载它自己，流程随之中止。面板把该行标「手动更新」，点开给一条 CLI 命令（路径按你本机客户端的安装位置自动生成），复制执行即可，**不需要先卸载**。
- 安装/更新默认**不会自动启用**插件。本次更新过但仍关闭的，顶部提示栏会出现「启用已更新的 N 个插件」按钮，只动这次更新过的包。
- 桌面端点「重启 dsh」后 dsh 先退出，再由客户端弹出官方的「应用无法启动或已意外停止」对话框，**在那里点「重启」才真正拉起来**（也可手动退出后重开）。
- 取消只作用于你点的那一项，后续排队项会继续装。面板比对走 npm 官方 registry，安装走你本机 pnpm 配置的源（如 npmmirror 镜像）；两步法更新前的来源预检问的是**同一个 pnpm 源**，所以镜像没同步的版本会直接判「更新失败」而不会先把插件卸掉。镜像未同步的新版本会出现「面板说有新版、装时报找不到版本」，稍后重试即可。
- 「本回合改动」卡只含文件工具的改动，按官方净变化口径计数；「官方那侧会不会画」的判断结果**只在本次连接内有效**（刷新或重连后重新判断），用于避免宿主恢复数据后出现双份卡。
- 会话已释放后「改动审查」由插件补位：数据来自会话日志里的编辑片段，同一文件的多处改动各自成段，行号靠反查当前文件内容对齐（精确到片段起点；多段时旧行号是推算值）。文件已被改得对不上时，该段标题会标「（片段内行号）」，行号退回片段内序号。
- 「DSH 不符」只在能确认版本时生效：本机版本读不到、或新版写的是 `^` / `~` 这类无法判定的范围，就不拦（宁可漏拦，不误伤正常更新）。
- 会话在用「自动审查」时，更新面板顶部会有琥珀色提醒：该模式下装/更新插件可能失败，工具调用也可能被审查拦掉（`503` / `429`）。按提醒切成「工作区内修改」，装完再切回即可。本插件**只提示，不改动你的权限设置**。
- 与启动器 dsh-web-shell 的分工：界面增强已由本插件接管；dsh-web-shell 的「检查更新」只负责 **dsh 本体**的比对与升级提示。
- 窗口记忆的归位发生在窗口显示后约 0.2~1 秒内，会有一帧跳变（官方客户端在插件加载前就把窗口显示出来了）；最小化不会中断记忆。
- 个别插件（如社区插件管理页扩展）自带单独的「检查更新」入口，与本插件互不关联，结果可能不同。
- **360 提示「PowerShell 执行攻击命令」是误报**：桌面端的窗口记忆需要在 dsh 进程外跑一个隐藏 PowerShell 小助手，360 对「非系统程序创建 powershell.exe」一律按高危拦截，选「允许」即可。dsh 官方桌面版每次启动自己也会创建隐藏 PowerShell，所以关掉窗口记忆也消不掉这个弹窗。

## 本人常用插件（可选）

> 本插件不会自动安装任何其他插件，也不属于必装项——不装同样能正常使用上述全部功能。

```sh
# 浏览器版
dsh plugin --profile web add <PluginName>
dsh plugin --profile web remove <PluginName>
dsh --profile web --dump-config | findstr /i <PluginName子串>   # 查看

# 桌面客户端（PATH 上的 dsh 装不了，用客户端自带的那份）
"<安装目录>\resources\runtime\cli\bin\dsh.cmd" plugin --profile desktop add <PluginName>
```

也可以直接在客户端「插件管理」中安装、卸载和查看。常用插件（web 与桌面端都能用）：

| 插件 | 用途 |
| --- | --- |
| `@changfenhuang/dsh-genui` | 生成式消息回复 |
| `@linxin666/dsh-session-archive` | 会话归档与批量清理 |
| `@liustack/modsearch` | 联网搜索 |
| `@michengai/dsh-skills-manager` | 技能加载与管理 |
| `@nimoxie/dsh-model-organizer` | 模型显示管理 |
| `@nimoxie/dsh-ui-tweaks` | 界面优化调整（本插件） |
| `cc-safety-net` | 危险命令与密钥防护 |
| `dsh-context` | 上下文管理 |
| `dsh-cost-meter` | 会话费用统计 |
| `dsh-ego-browser` | 模拟浏览器点击 |
| `dsh-ops` | bash / PowerShell 7 与 Rust 高性能工具 |
| `dsh-whale-widget` | 右下角小鲸鱼挂件 |
